
# Genetic Car Learning

Genetic algorithm that uses distance to wall as input to a quadratic and maximizes (is rewarded) to maximize lap time or distance travelled. Inspired by University homework of maximizing quadratic.

Plan to add sliders for car characteristicis and more realistic handling.
